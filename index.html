Mis cuatro ejercicios

Ejercicios con HTML, CSS y JavaScript

1. Calcular el numero Pi

Descripcion: Calcular una aproximacion del numero Pi usando la serie de Nilakantha.

Entrada: Cantidad de terminos.

Salida: Valor aproximado de Pi.

2. Ecuacion cuadratica

Descripcion: Resolver una ecuacion de la forma ax² + bx + c = 0.

Entrada: Valores de a, b y c.

Salida: Soluciones de la ecuacion.

3. Los 35 camellos - Capitulo 3

Descripcion: En el libro El hombre que calculaba, tres hermanos deben repartir camellos. El mayor recibe la mitad, el segundo un tercio y el menor un noveno.

Entrada: Cantidad de camellos.

Salida: Cantidad para cada hermano, camellos prestados y sobrantes.

4. Los 8 panes - Capitulo 4

Descripcion: Dos viajeros comparten sus panes con una tercera persona. Los tres comen partes iguales. El invitado entrega monedas, que se reparten segun el aporte de cada viajero.

Entrada: Panes de cada viajero y cantidad de monedas.

Salida: Monedas que recibe cada viajero.
